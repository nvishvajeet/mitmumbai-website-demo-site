# MIT Mumbai website demo — published site

Rendered output of the `mitmumbai-website-demo` repository, served by GitHub
Pages at <https://mitmumbai-demo.vishwanathgrid.org>.

**This is not an official MIT Mumbai website.** It is a concept demonstration
built from MIT Mumbai's own published content, captured on 25 July 2026. Every
page says so, every page carries `noindex, nofollow`, and `robots.txt`
disallows all crawling.

Do not edit this repository by hand. Change the source repository and run
`python3 tools/publish_site.py --push`.
